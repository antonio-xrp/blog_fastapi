
# Diseño API

```mermaid

flowchart TD
    A["Cliente / Frontend"] --> B["Enviar petición HTTP"]
    B --> C{"¿Qué módulo?"}

    C -->|Users| U["Operaciones de usuarios"]
    C -->|Posts| P["Operaciones de publicaciones"]
    C -->|Auth| AU["Autenticación y recuperación"]

    U --> U1["Crear, consultar o actualizar perfil"]
    P --> P1["Crear, listar, consultar, actualizar o eliminar posts"]
    AU --> A1["Login, validar identidad, cambiar o recuperar contraseña"]

    U1 --> R["Construir respuesta HTTP"]
    P1 --> R
    A1 --> R

    R --> Z["Cliente recibe respuesta"]

```
## Users

```mermaid

flowchart TD
    A["Módulo users"] --> B{"Operación"}

    B -->|Registro| C["Validar username, email y password"]
    C --> D{"¿Datos válidos?"}
    D -->|No| E["422: Datos inválidos"]
    D -->|Sí| F{"¿Username o email ya existe?"}
    F -->|Sí| G["409: Usuario duplicado"]
    F -->|No| H["Aplicar hashing a la contraseña"]
    H --> I["Crear usuario en USERS"]
    I --> J["201: Usuario creado"]

    B -->|Consultar perfil| K["Identificar usuario objetivo"]
    K --> L{"¿Existe?"}
    L -->|No| M["404: Usuario no encontrado"]
    L -->|Sí| N["Devolver datos públicos del usuario"]

    B -->|Actualizar perfil| O["Validar autenticación y permisos"]
    O --> P{"¿Puede actualizarlo?"}
    P -->|No| Q["401 o 403"]
    P -->|Sí| S["Validar cambios y actualizar USERS"]
    S --> T["Devolver perfil actualizado"]

    B -->|Eliminar cuenta| V["Validar autenticación y permisos"]
    V --> W{"¿Puede eliminarla?"}
    W -->|No| X["401 o 403"]
    W -->|Sí| Y["Eliminar usuario según reglas de integridad"]
    Y --> Z["204: Cuenta eliminada"]


```

## Auth

```mermaid

flowchart TD
    A["Petición al módulo auth"] --> B{"Operación"}

    B -->|Login| C["Recibir email y contraseña"]
    C --> D["Buscar usuario por email"]
    D --> E{"¿Usuario existe y contraseña válida?"}
    E -->|No| F["401: Credenciales incorrectas"]
    E -->|Sí| G["Generar access token"]
    G --> H["Devolver access_token y token_type"]

    B -->|Endpoint protegido| I["Recibir access token"]
    I --> J["Validar firma, expiración y claims"]
    J --> K{"¿Token válido?"}
    K -->|No| L["401: No autenticado"]
    K -->|Sí| M["Identificar usuario"]
    M --> N["Permitir continuar con la operación"]

    B -->|Olvidé contraseña| O["Recibir email"]
    O --> P["Responder de forma genérica"]
    P --> Q{"¿Existe usuario?"}
    Q -->|No| R["No revelar si la cuenta existe"]
    Q -->|Sí| S["Generar token de recuperación aleatorio"]
    S --> T["Guardar hash y expiración en PASSWORD_RESET_TOKENS"]
    T --> U["Enviar enlace de recuperación"]

    B -->|Restablecer contraseña| V["Recibir token y nueva contraseña"]
    V --> W["Calcular hash del token recibido"]
    W --> X["Buscar token almacenado"]
    X --> Y{"¿Existe y no expiró?"}
    Y -->|No| Z["Rechazar recuperación"]
    Y -->|Sí| AA["Aplicar hashing a la nueva contraseña"]
    AA --> AB["Actualizar USERS.password_hash"]
    AB --> AC["Invalidar token de recuperación"]
    AC --> AD["Confirmar restablecimiento"]

    B -->|Cambiar contraseña| AE["Usuario autenticado"]
    AE --> AF["Recibir contraseña actual y nueva"]
    AF --> AG["Verificar contraseña actual"]
    AG --> AH{"¿Coincide?"}
    AH -->|No| AI["Rechazar cambio"]
    AH -->|Sí| AJ["Aplicar hashing a la nueva contraseña"]
    AJ --> AK["Actualizar USERS.password_hash"]
    AK --> AL["Confirmar cambio"]

```


## SCHEMAS

### USERS

- UserBase(BaseModel)
    - username
    - email

- UserCreate(UserBase)
    - password

- UserPublic(ORMModel)
    - id
    - username
    - image

- UserPrivate(UserPublic)
    - email

- UserUpdate
    - username
    - email

### AUTH

- Token(BaseModel)
    - access_token
    - token_type

- ForgotPasswordRequest(BaseModel):
    - email

- ResetPasswordRequest(BaseModel)
    - token
    - new_password

- ChangePasswordRequest(BaseModel):
    - current_password
    - new_password


### POSTS

- PostBase(BaseModel)
    - title
    - content

- PostCreate(PostBase)
   
- PostResponse(PostBase, ORMModel)
    - id
    - user_id 
    - date_posts
    - author:UserPublic

- PostUpdate(BaseModel)

- PaginatedResponse(BaseModel)
    - list[PostResponse]
    - total
    - skip
    - limit
    - has_more

## Catálogo de endpoints

| Método HTTP   | Endpoint                      | Objetivo                              | Acceso                        |          
|---            |---                            |---                                    |---                            |
| POST          | `/api/users`                  | Registrar un usuario                  | Público                       | 
| GET           | `/api/users/me`               | Consultar mi perfil                   | Autenticado                   |
| PATCH         | `/api/users/me`               | Actualizar mi perfil                  | Autenticado                   |
| PATCH         | `/api/users/me/picture`       | Actualizar mi foto de perfil          | Autenticado                   |
| POST          | `/api/users/token`            | Iniciar sesión y obtener un token     | Público                       |
| POST          | `/api/users/forgot-password`  | Solicitar recuperación de contraseña  | Público                       |
| POST          | `/api/users/reset-password`   | Restablecer contraseña                | Token de recuperación válido  |
| GET           | `/api/posts`                  | Listar publicaciones                  | Público                       |
| POST          | `/api/posts`                  | Crear una publicación                 | Autenticado                   |
| GET           | `/api/posts/{post_id}`        | Consultar una publicación             | Público                       |
| PATCH         | `/api/posts/{post_id}`        | Actualizar una publicación            | Autor autorizado              |
| DELETE        | `/api/posts/{post_id}`        | Eliminar una publicación              | Autor autorizado              |
